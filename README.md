## Getting Started

1. **Clone the repository:**
    ```bash
    git clone https://github.com/Aiswaryabinu/Portfolio.git
    ```

2. **Navigate into the project directory:**
    ```bash
    cd Portfolio
    ```

3. **Open `index.html` in your browser, or use a live server if using a framework.**
